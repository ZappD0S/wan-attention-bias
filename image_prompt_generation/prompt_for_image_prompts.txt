I need a batch of 10 prompts for generating images that depict scenes with two ‘characters', which may also include inanimate objects. The background should be simple or neutral so that the focus remains on the characters. The characters should be similar to each other, or even identical, and fully in focus.

I will use these images to generate videos in which the characters perform different actions independently. Therefore, for each prompt I also need a second prompt that describes each character performing its action independently (for example, 'the cat jumps', 'the car stops' or the 'the glass breaks'). The first prompt should only describe the characters appearance and should not include any mention of their action. The action should be described only in the second prompt.

The actions must always be distinct and should be dynamic, but they should not require the characters to move significantly within the scene. Each character should perform exactly one action, and it must be something they could realistically do (for example, 'the dog flies' is not allowed). The scene must provide enough space for all characters to perform their actions without colliding or overlapping. If an action requires a certain part of the character to be visible you must declare it explicitly in the appearance prompt.


The output must be formatted as a JSON file. Use the key "appearance_prompt" for the appearance prompt and "action_prompt" for the action prompt.

Each prompt must be divided into multiple segments, where each segment is a separate string describing either part of the character’s appearance or part of the character’s action. When all segments are joined together with a single space, they must reconstruct the original full prompt.
Each character-specific segment must make sense on its own and must contain the subject; segments that rely on ambiguous references (e.g., starting with “the other …”) are not allowed. The locative expressions that identify the characters (e.g."on the right" or "on the left") must not be part of the character segments. If needed, include additional connective segments to ensure the full prompt reads naturally.

There must be exactly one character-specific segment for each character in the scene. For the action prompt, each character-specific segment must include that character’s action.

For both prompts, include two arrays inside each prompt object: "segments" and "mask". The segment array must contain all of the prompt’s segments in order. The mask array must contain a sequence of 1s and 0s indicating which segments describe individual characters (1) and which describe general or connective information (0). The number of 1s in each mask must equal the number of characters in the scene. Mark only the segments that describe specific characters; do not mark segments that refer to all characters collectively (for example, ‘there are three dogs’).
